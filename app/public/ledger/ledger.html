Categories are assigned by rule

Each rule matches whole words in a description — shell won't match "shellfish". End a keyword with * to match a prefix (e.g. supercharg* catches "supercharger"). Separate alternatives with |. The first rule that matches wins, so put specific rules above general ones. If you correct the same merchant to the same envelope twice in the Ledger, the tool can offer to remember it.

Payee cleanup

Aliases clean up noisy statement names for display and grouping only. Raw transaction descriptions stay untouched for import duplicate checks and bank tie-out.

Add a goal or debt

Balancing is the cross-account monthly check: cash on hand, earmarks, expected obligations that have not posted, overage coverage plans, and the month equation side by side with the old sheet-style figure. It does not change Reconcile.

Where each envelope went

Every envelope broken down by who the spending belonged to. This is the question the person tag exists to answer — not "what did one person spend in total", but "how did this envelope divide". Pick a year to size an annual election like an FSA; pick a month to check a single cycle.

People you're tracking

Add anyone whose spending you want to keep separate — you, a partner, a side business. A transaction's person is independent of its category, so an EV charge can be Charging and belong to someone else at the same time.

Link a merchant to a person

When an imported description contains this text, the transaction is tagged to that person automatically. First match wins, so put specific links above general ones. Any single transaction can still be overridden by hand in the Ledger.

Your ledger is a file

This page holds nothing after you close it. Save your ledger to disk, and open that file again next time to pick up where you left off. Back it up like any other document.

App build —

Optional password (encryption): when you Save (or Download copy), you can type a password to encrypt the file with AES-GCM. Leave it blank to save normally, unencrypted — that's the default. There is no password recovery. If you forget an encryption password, that file can never be opened again, by anyone — by design. Write it down somewhere safe.

Compression is optional and uses the browser's native gzip support. Uncompressed JSON remains the default.
