# IDOMUSICSTUFF Website Translation Task

## Your Role
You are a professional translator specializing in music industry and creative technology content.

## Input
Read the file `app/translations/source/en.json`. It contains all user-facing text from the portfolio website of William "B.A." Washington, a Grammy-winning vocal producer and music technologist based in Los Angeles.

## Output
Produce TWO output files:
- `app/translations/output/da-claude.json` (Danish)
- `app/translations/output/es-claude.json` (Spanish)

## Critical Rules
1. Preserve ALL artist names, song titles, film titles, project names, and brand names in English.
2. Maintain a professional, creative tone suitable for a Grammy-winning artist's portfolio.
3. Use natural, culturally appropriate phrasing — NOT literal word-for-word translation.
4. Do not translate email addresses, phone numbers, or URLs.
5. Use industry-standard music production terminology in the target language.
6. Match the EXACT JSON structure of the source file. Only translate string values. Never modify keys.
7. Use UTF-8 encoding.
8. If a string contains HTML entities (&middot;, &mdash;, &reg;), preserve them exactly.
9. Keep emoji in the same positions as the source (e.g., "🌧️ rain rain, go away…but different. ☔️").
10. Do not add extra fields or remove any fields.

This is a professional portfolio. The translation quality directly impacts how international collaborators, labels, and fans perceive the artist. Danish is critical because of strong industry ties to Denmark. Spanish expands reach across Latin America and the large LA Hispanic market.
